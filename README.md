# 初中英语 · Chinese junior-high English (WeChat mini program)

The sister app of `dzonglee/chinese-junior-high-maths`: textbook-synced lessons for mainland
junior-high English plus exam-focused drilling for 中考英语, routed by the learner's city, school
structure, grade and textbook edition.

**Status: Stage 1, resource gathering.** No app code yet. The first job is to build a verified,
rights-labelled research corpus, matching the one behind the maths app: curriculum standard,
textbook editions, every priority city's 中考英语 papers, answer keys, listening audio and
transcripts, 听说 (speaking) test formats, vocabulary lists and writing rubrics.
