# Annual official English-exam announcement search

`coverage.json` accounts for all 56 priority cities × 2022–2026 separately from the vocabulary grid.
`query-ledger.json` records 252 actual annual Ministry-index searches and three positive controls.
Every downloaded returned-URL TXT is listed in the unit download manifest, opened and byte/SHA checked.
Exact native submitted/parsed queries match the ordinary published-form return; no native token or API
request was synthesized or replayed. The automatic audit validates those relationships.

`existing-official-cross-references.json` preserves 28 existing source-unit notice/policy/direct-attempt
cells, with local registered source IDs and original immutable branch/source-register pins. North/east
includes eight verified notice cells and two blocked original English-notice requests. South/central-west
includes thirteen annual notice/policy cells and five explicitly cohort-spanning policy cells. Original
verification, dates and applicability limits survive; no separately issued annual notices are invented.

New index queries are restrictive city/year/English/junior-high-exam/notice/intended-issuer attempts,
not exhaustive municipal archives, acquired underlying notices or newly established blueprint facts.
Only minimal metadata and actual URL response text are retained. No native bodies, snippets, personal
list details or ephemeral values are copied. Zero query hits do not establish local absence.

`north-east/` and `south-cw/` retain the immutable delegate metadata packages. Their counts and original
source IDs are provenance snapshots; the combined ledgers and unit register contain the coordinator's
local source/file ID mappings. Nothing here grants commercial permission or supplies app content.
