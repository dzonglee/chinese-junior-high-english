# Source count reductions

A source-card calculation of kind `count` may define `reduction` with whole-number before/after quantities from 0 to 9999, unit and distinct period labels. Before must be at least after and the declared answer must equal their difference. This is a reduction comparison, not an increase, percentage, environmental-impact model or causal estimate.

The three bars show the source before quantity, source after quantity and learner’s actual valid integer input. They share a scale based on the largest visible value (at least 1). An invalid/empty input is shown as an em dash with no attempted bar, never silently clamped or substituted with the answer. Exact labels retain the source counts even if an oversized attempt changes the scale.

The attempted bar is neutral while editing, red after a wrong check and green after a correct check; text feedback supplies the reason. Input edits invalidate completion; wrong input and source clues survive restoration. Correct arithmetic still requires source evidence and the learner’s own explanation. Guided work creates no independent attempts/mastery/lessonDone. Inspect the complete chart and wrong/repair/clear states in browser/native; numeric labels are code, not generated art.
