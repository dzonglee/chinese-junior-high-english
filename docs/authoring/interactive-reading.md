# Reading with changing situations

A reading lesson may use an existing `transform` workshop when the learner needs to manipulate
participants, records or conditions. Keep rules explicit in the current task; a generated picture
cannot establish an event history. Use literal code records for identities, quantities and sequence.
Use `world.layout: stacked` for a vertical diagram when English phrases would be too narrow in parallel columns. Both web and native render the same opt-in. Changing the situation must change the required choice, rather than repeatedly accepting one answer.

Set `workshop.applicationStyle` to `cards` to use the existing one-fragment-at-a-time evidence
browser during reading/transcript applications. This is independent of the workshop's activity kind.
Proof source cards still require their own `sourceStyle`, complete material and literal quotations.
Web and native templates use the same opt-in. Opening a checked explanation hides the separate
fragment browser until the explanation is closed; changing questions closes the old explanation.

The sports lesson uses a four-person original portrait for selection, distinct-player sets derived
from code pass logs, and a separate five-player transfer diagram. Repeated touches do not create
extra players, permission to attempt a score does not guarantee a point, and every part of a
combination answer must satisfy the passage. Its rendered review is separate from engine coverage.

People selections show a dot before checking, a cross for a checked wrong person, and a tick only when the complete selected participant set is correct. Removing a required person clears completion and retains the unfinished selection on reload.

Accepted picture evidence stays visibly marked while the learner selects another required quotation. The active quotation and accepted premises are separate states; a wrong picture shows a cross without erasing an already accepted premise. This does not complete an unfinished argument.

Stacked record-and-conclusion tasks use full-width, larger quoted-record rows in both web and native templates. Keep the diagram to the selected record and its conclusion when another generic source box adds no information.
