# Artwork delivery roots

The inspected `assets` and `illustrations` roots remain unchanged. New source-card illustrations can use `illustrations-2`, a separately registered asynchronous subpackage loaded before catalog readiness. Each root retains the 1,500,000-byte safety limit; main/total limits remain 1,900,000/19,000,000 bytes. Never raise a budget to fit new art.

Build discovery uses the visual provenance register. Source illustrations explicitly name the root. Native development/cloud adapter checks must load every registered root, resolve each lesson image, and exercise each root’s failure/retry path. Browser delivery embeds registered lesson derivatives. The isolated guest-native run must verify the actual image path and rendered action alternatives.
