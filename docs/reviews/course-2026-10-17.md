# Complete original course · bounded review, 2026-10-17

The local course contains 413 original draft lessons, 4,804 tasks, 1,690 distinct headwords and
245 topic packs. It covers 29 themes in reading/listening/speaking/writing, 58 grammar objectives
and eight pronunciation-knowledge units. Every topic/task/word is assigned to immediate/delayed
lessons. This is the project's original grade/term sequence, not verified publisher-unit alignment
or an exact official local/national wordset. No reference material was copied into learner packs.

## Source review and corrections

Two authorized existing delegates authored vocabulary and thematic reading/expression sources,
then independently reviewed other lanes. Coordinator inspected the patches and applied corrections.
The reading review covers 58 original passages and 232 questions. The expression review covers
348 oral/written tasks over 174 intentionally shared cross-modal scenarios. All 330 explicit
length requirements were checked; no failure remains. Vocabulary review checked all 1,594 new
headwords, original examples/translations/notes, exact target occurrence and genuine variants;
96 existing headwords remain. One old discover example was corrected to allow exact masking.
The grammar/pronunciation/listening/legacy-expression review covers 572 authored cases.

Concrete corrections include ambiguous reflexive and conjunction distractors, explicit intended
meaning for indefinite pronouns, context-specific Chinese feedback, a duplicated English “from”,
ordinary modal wording, reading negatives unsupported by the text, and expression prompts/models
with missing time or closing-summary requirements. Capitalization tasks explicitly opt into case
sensitivity. Other tasks retain case-insensitive duplicate-option protection.

Full-course lifecycle tests exposed a feedback leak: one shared-passage review answer revealed
later answers, preventing independent completion. Reviews now withhold all feedback and learning
evidence until submission, including after reload. Self-marked work advances practice scheduling
without becoming measured retention. Immediate spelling after a meaning reveal counts as assisted.
Generated compact catalog arrays preserve the exact runtime shape; the existing package limits
were retained rather than raised to accommodate the larger course.

## Rendering and visual review

All 4,804 instructional figures were rendered at 320, 390 and 768 CSS-pixel widths with zero
horizontal overflow. The coordinator inspected sheets 07–10 (64 representatives); delegates
inspected sheets 01–06 (96) and 11–16 (85), totaling one representative per topic. Four real app
states were inspected: inventory, oral self-review, pronunciation knowledge and vocabulary.
This does not constitute individual editorial approval of every question or native-device review.

The review found restoration evidence ending midword and exposing an internal placeholder.
The compiler now uses the complete target paragraph and normalizes gap markers, with regression
checks for all ten restoration questions. Some sheets appeared to lose leading glyphs in scaled
previews. Enlarged read-only inspections confirmed complete headings in the PNG pixels; no source
or app clipping was reproduced. Captures also use an isolated page per sheet and await font
readiness and two paint frames. Retaken sheets retain complete evidence and legible text.

`npm run check` passes TypeScript and 511 tests, including every lesson's actual checked pack,
controller, saved progress and distinct delayed review. Real missing-audio lessons reject entry;
synthetic playback exists only in lifecycle tests. Seven grammar regressions, four actual-native-
source recording simulations, 11 browser journeys, seven offline checks and six expanded-course
browser checks pass. Course coverage, content audit, 24-route package checks, development and
synthetic-cloud native adapters, and release rejection guards pass. Main/development budgets are
approximately 1,641/10,038 KB; portable HTML is 10.04 MB with all packs and three Blender assets.

Managed Chromium blocks direct file navigation. Offline checks serve the exact standalone HTML
on loopback and then disable networking; direct-file navigation remains unvalidated here. API
simulations and static WXML checks do not replace WeChat DevTools, a real microphone/device,
editorial approval or publication. All 99 listening scripts are authored but approved audio is
pending for 31 lessons. Pronunciation units teach written knowledge, not measured speech.
Videos remain deferred. No research gate, release or external MCP write is claimed.
