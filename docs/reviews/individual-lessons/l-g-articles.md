# l-g-articles · first sound, then reference

Authoring date: 2026-10-18 (Sydney). Content remains draft. Individual visual/control review passed.

## Teaching decision

The inspected original book/umbrella illustration is a required object-selection task. A student
must identify the named object as well as choose a/an. Exact names and first-sound clues are code.
Subsequent tasks change the phrase, not just the answer: book → old book → useful book. Students
must choose the relevant first word or sound evidence; looking only at the noun or first letter
cannot bypass that requirement.

Nine tasks cover an umbrella, a book, an old book, a useful book, an honest student, a university,
an hour, The book referring back to the same book, and general plural books with no article.
Both sound and reference judgments have specific wrong-path feedback. The ∅ notation is explicitly
explained as no article. Written sound clues are not presented as listening practice.

## Whole lesson

Prediction introduces the umbrella. Distinct applications check a known classroom door and a
useful map. A fresh unusual-map transfer requires an / The, preventing the false shortcut that
all u-words take a. It also checks the same-object reference independently of pronunciation.
Every distractor has a reason. Delayed items remain unexposed; guided work creates no independent
attempts, mastery or lesson pass.

## Inspected evidence

All nine models, wrong object/first-word evidence and transfer were inspected. Review removed
a location mismatch between a desk picture and a bag sentence, made wrong-object feedback direct,
shortened the honest prompt and removed an incorrect verb-role highlight from a noun phrase.

Typecheck, compiler and all-lesson teaching/spelling audit pass; core 1,452 was last run before
