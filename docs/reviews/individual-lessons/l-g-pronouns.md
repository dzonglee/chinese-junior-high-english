# l-g-pronouns · keep the referent, change the grammatical position

Authoring date: 2026-10-18 (Sydney). Content remains draft. Individual visual/control review passed.

## Teaching decision

The known three-person illustration supplies selectable referents. The prompt now explicitly asks
who the missing pronoun refers to; it does not incorrectly call every pronoun a subject. Students
must select the full group as well as the correct form. Code supplies ownership and making records:
merely holding a book does not prove owning it or making a model.

Eight tasks contrast object her, typed her book / hers, subject She, object after to (him), plural
object them, independent possession theirs and first-person plural reflexive ourselves. The book
first belongs to Mia, then an explicitly changed record makes it jointly owned. We is explicitly
spoken by Mia for herself and Amy, so they/themselves cannot replace the first-person group.

## Whole lesson

Prediction uses Mia/like her. Distinct applications require yours and ourselves with another
speaker group. A fresh twins/drawings transfer requires them / theirs: the referents stay the same
while grammatical positions differ. Every wrong option has its own reason. Original delayed items
remain untouched; no guided action grants independent assessment, mastery or lesson pass.
