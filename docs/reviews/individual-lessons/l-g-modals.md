# l-g-modals · separate the meaning from the verb form

Authoring date: 2026-10-18 (Sydney). Content remains draft. Individual visual/control review passed.

## Teaching decision

An original generated pool-gate scene anchors a real prohibition. Closed / No entry is rendered
in code on its blank sign, readable at 320px. Swimming ability is separate written evidence;
a still picture never proves ability or permission. Learners first select the relevant meaning,
then express it. A correct modal stays blue when the selected premise is wrong.

Eight tasks distinguish prohibition, no requirement, ability, permission and advice, then require
typed base verbs after can/must and a meaningful negative answer to Must. Valid alternatives
such as needn't / don't have to are acknowledged rather than described as ungrammatical. The
permission exercise does not label can incorrect. Every task supplies its own facts.
