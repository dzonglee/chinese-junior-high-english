# l-g-relatives · find the antecedent, then build its description

Authoring date: 2026-10-18 (Sydney). Content remains draft. Individual visual/control review passed.

## Teaching decision

Eight tasks connect a concrete antecedent with its relative clause. The original class photo is
now a silent reference scene: learners select Leo/the boy or Mia and Amy/the girls before building
the description. No speaking/listening roles are invented. Wrong reference frames remain separate
from a correctly built clause; singular/plural agreement follows the antecedent, not nearby Leo
or the two bags in a later modifier.

Tiles expose repeated he/it, subject versus object omission, whose ownership and the difference
between a place adverbial and a subject. who/that, which/that, object-relative omission and five
valid locative constructions are accepted. The finite-clause tasks explicitly retain a relation
word where a reduced participle phrase would be a different requested construction. A preposition
can move to the end and its object-relative pronoun can be omitted; those forms are not graded wrong.
