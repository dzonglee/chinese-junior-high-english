# l-g-comparison · select the comparison set, then produce the form

Authoring date: 2026-10-18 (Sydney). Content remains draft. Individual visual/control review passed.

## Teaching decision

The learner taps measured bars to include everyone in the actual comparison. The same three
height records support a pairwise taller/shorter statement and a group-wide tallest statement.
Selecting only the grammatical subject does not identify the full group. Incorrect extra members
turn red; a correct adjective cannot bypass the wrong group.

Eight tasks contrast pair/group scope, the reverse shorter viewpoint, heavier bags, equal bags
with as heavy as, a long-adjective comparative, irregular better and easy → easier. Later tasks
require actual typing, with an optional reference. The live diagram retains more better/easyer
until the student repairs the input. Measurement labels and scales are code, never inferred from
illustration perspective. All bars use equal-width rails at every supported width.

## Whole lesson

Prediction compares Amy/Mia. Distinct applications correct easier and compare another pair of
bags. The fresh red/blue/green-box transfer requires heavier / the heaviest from 3/2/5 kg records;
three visible objects do not make both sentences superlative. Each wrong option has a reason.
Delayed items remain unexposed. Guided work creates no independent attempts, mastery or pass.

## Inspected evidence

All eight models, wrong group, typed mistakes, application and transfer were inspected. Review
made chart columns equal-width and compact at narrow widths. Complete real-control flow and 24
task × width checks pass, with reload and no assessment records. All 1,454 core tests, typecheck,
826 teaching/spelling audit and static package checks pass. A combined spelling audit timed out
once and passed alone; it is now two independent American/British audits, each covering all 413
lessons and all 1,690 headwords under the unchanged five-second timeout. No coverage was removed.
This remains local browser/adapter evidence, not new native GUI or editorial release approval.
