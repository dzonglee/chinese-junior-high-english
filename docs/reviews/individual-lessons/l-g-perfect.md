# l-g-perfect · connect past events to a present result

Authoring date: 2026-10-18 (Sydney). Content remains draft. Individual visual/control review passed.

## Teaching decision

An inspected original lost/found-key picture is actionable evidence. Students tap the panel whose
present consequence matches the sentence; selecting keys found cannot support still unable to
open the door. The full predicate is checked separately. Changing speaker from Mia to I changes
has to have, while found stays the participle.

Eight tasks cover has lost, has found, have found, a yesterday/that evening past narrative,
see/saw/seen, ongoing residence, since with a starting point and for with a duration. Selecting a
residence record that ended last year shortens the time band; it cannot support still living here.
The band and marker render the selected evidence, even when it is wrong. A record's past event
label is separate from its present-result label, avoiding a current state plotted in the past.

## Whole lesson

Prediction uses the original key-loss question. Distinct applications require has finished and
have read. A fresh bike-repair transfer contrasts a current usable result with a separate repair
yesterday. Each wrong option has its own reason. Original delayed items remain unexposed; no
assisted action grants independent marks, mastery or lesson completion.

## Inspected evidence

All eight models, incorrect picture/result, ended residence, application and transfer were
inspected. Review corrected a misleading timeline label, reordered the since/for diagram into
English phrase order, used the neutral term time word, and removed an accidentally repeated
sentence. These fixes were rebuilt before final checks.

The whole real-control flow, 24 task × width checks, timeline alignment, reload and zero
assessment records pass. All 1,452 core tests, typecheck, 826 spelling/teaching audit and static
package checks pass. Main package is 1,699 KB within its unchanged 1,900,000-byte guard. This is
bounded local evidence, not native GUI or editorial release approval.
